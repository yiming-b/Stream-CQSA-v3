Goal: a self-contained tarball the user untars on CITA (H100, no network; python 3.12.7, torch 2.13.0+cu129,
triton 3.7.1) and runs with no network: `setup_cita.sh` (wheels offline, stream_cqsa in three tiers: Triton /
classic CUDA / wave CUDA), `run_cita.py` (executes `run_cita.ipynb` with nbclient: environment, correctness,
E0, E1 fwd, E1 fwd+bwd, E3 fwd, E4, E6, report, results tarball). Spec: the task message of 2026-10-22.
