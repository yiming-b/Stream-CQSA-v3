## Design as built (summary; details in the source headers)

- **One layout: uniform.** W >= 1 subproblems padded to S = ceil(max L / 128) * 128 rows, grid (S/128, W, H), every
  per-subproblem table at `bidb * stride` (0 for a classic call, which is therefore a W=1 wave), plus `lens[W]`
  (real rows per subproblem): row blocks past `lens[w]` exit, the key loop stops at `ceil(lens[w] / kBlockN)`, the
  ragged last tile takes upstream's `Is_even_MN=false` predication/mask. That makes the uniform layout serve
  causal AND non-causal, gathered AND in place for ANY N (no `N % 128 == 0` gather, no 0*NaN hazard), so the
  varlen wave layout (`cu_seqlens`, `cqs_blk_cu`, `cqs_bb_cu`, forward modes 2/4-varlen) is retired.
- **Forward**: memset(route[W]) -> census (one warp per (subproblem, row block), runs at
  `(bidb * run_stride + m) * 16`, `atomicOr(route[bidb])`) -> ALIGNED wave kernel (v12f's loop; returns if
  `route[bidb] != 0`; in-place block-map delta of the NEXT live tile looked up with the run-table step, before the
  QK GEMM) -> LEGACY (v11's loop with the per-subproblem offsets; returns if `route[bidb] == 0`). One stream, no
  host sync. Descending row-block order for causal (`cqs_reverse_m`), as v12f.
- **Backward**: the same per (subproblem, column block): census -> ALIGNED (v12b's loop, Dpsum_smem) -> LEGACY ->
  convert_dQ. Uniform layout too: packed q/k/v/dout `[W*S, H, D]`, lse/dpsum `[W, H, S]`, dq_accum `[W*S, H, Dr]`.
- **TU split**: `flash_fwd_hdim{64,128}_{fp16,bf16}{,_causal}_sm80.cu` (plain + ALIGNED) /
  `..._legacy_sm80.cu` (v11 LEGACY, wave offsets); `flash_bwd_hdim*_{fp16,bf16}_sm80.cu` /
  `..._legacy_sm80.cu`; `cqs_census.cu`, `cqs_census_bwd.cu`, `wave_kernels.cu`. Kernel sets `common`
  (fp16+bf16, hdim 64+128) and `native_v2_dev` (hdim64 fp16).

## What the combined job produces (part script `slurm/ultimate/parts/u2.sh`)

`results/ultimate/wave_ab.json` and `wave_ab.md` (written by `benchmarks/ultimate/wave_ab.py`; `--report` re-renders
the markdown from the JSON). Rows: `fwd` and `bwd` for N=131072 c=7 (W=7, one launch), N=131072 c=73 (W=73, one
launch), N=1048576 c=7 (the engine's default-budget waves: 2 subproblems per launch, 4 launches, per-wave medians
summed); `engine` rows per config (wave_forward gathered / in place and wave_backward on cqsa_native_v2 and on
cqsa_native). How to read `wave_ab.md`:

- **Targets** section (03_kernels_report.md 9, U2): `W=1 v2 / v12f` and `W=1 v2 / v12b` within 1% (the classic
  call pays nothing for the wave layout: design 4.5); `c=73 one-launch forward / monolithic flash_attn <= 1.10`
  (the per-task v12f loop was 1.202x); `old bwd_wave / v2 >= 2x`. Each line says met / NOT met.
- Forward table: `v2 wave` (gathered) and `v2 in place` vs `old wave` / `old in place` (cqsa_native) vs the
  `v12f loop` / `v11 loop` (one launch per task) vs the monolithic flash_attn / SDPA at N; `v2 / v12f loop` is the
  gain of one launch over the per-task loop (the per-call fixed cost and the grid tails), `v2 / old` the gain over
  the first wave module; `equal v12f` / `equal old` must be True (NaN-pre-filled outputs; finite inputs), routes
  `[0]` (every subproblem ALIGNED). The kernel-kind line gives census / ALIGNED / LEGACY-no-op device us per wave.
- Backward table: the same with `v2 bwd wave` vs `old bwd wave` vs the `v12b loop`; `dk/dv equal v12b` True and
  `dq max d` within the fp32 atomics' drift (<= ~2e-4 at these magnitudes).
- Engine table: end-to-end seconds-level sanity of the module switch (tables, gathers, merges included).
- "Failed arms" / "Errors" sections must be absent; a present one names the arm and its exception.
